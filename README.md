## ✍️ How I work

**Find the real problem.** Start with what someone needs to do. Shape the experience and the architecture around that, then make the first useful version.

**Build the whole thing.** Interface, backend, payments, deployment. I direct AI coding tools, review their output and connect the pieces into a working product.

**Care after it ships.** App Store reviews, unexpected bugs, the details you only notice in use. I stay with the product and keep making it better.
